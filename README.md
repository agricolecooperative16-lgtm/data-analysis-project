# 📊 نظام تحليل المبيعات والعملاء

[![Python Version](https://img.shields.io/badge/python-3.7-blue.svg)](https://www.python.org/downloads/)
[![Flask](https://img.shields.io/badge/flask-2.0-green.svg)](https://flask.palletsprojects.com/)
[![License](https://img.shields.io/badge/license-MIT-orange.svg)](LICENSE)

نظام متكامل لتحليل المبيعات والعملاء مع واجهة ويب تفاعلية، يدعم تحليل RFM، التنبؤ بالمبيعات، والتحليل الموسمي.

## ✨ الميزات

- 📊 **لوحة تحكم تفاعلية**: مؤشرات الأداء الرئيسية واتجاه المبيعات
- 👥 **تحليل RFM**: تقسيم العملاء إلى شرائح (VIP، Loyal، Potential، At-Risk، Lost)
- 🔮 **التنبؤ بالمبيعات**: نماذج الانحدار الخطي ومتعدد الحدود
- 🌦️ **التحليل الموسمي**: تحليل الاتجاهات الشهرية والأسبوعية
- 📄 **تقارير PDF**: تصدير تقارير كاملة بصيغة PDF
- 📈 **رسوم بيانية تفاعلية**: تصور البيانات باستخدام Chart.js

## 🛠️ التقنيات المستخدمة

- **Python 3.7+**
- **Flask** - إطار العمل الخلفي
- **Pandas** - معالجة البيانات
- **Scikit-learn** - نماذج التعلم الآلي
- **Chart.js** - الرسوم البيانية التفاعلية
- **ReportLab** - إنشاء تقارير PDF

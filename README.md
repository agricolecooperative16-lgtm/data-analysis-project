# نظام تحليل المبيعات والعملاء

نظام متكامل لتحليل بيانات المبيعات والعملاء باستخدام تقنيات RFM والتنبؤ والتحليل الموسمي.

## 🚀 الميزات

- **تحليل RFM**: تقسيم العملاء حسب السلوك الشرائي
- **التنبؤ**: توقع المبيعات المستقبلية باستخدام نماذج متعددة
- **التحليل الموسمي**: اكتشاف الأنماط الموسمية في البيانات
- **تحليل الاحتفاظ**: حساب معدل الاحتفاظ بالعملاء
- **CLV**: حساب القيمة الدائمة للعميل
- **تقارير تفاعلية**: لوحات تحكم باستخدام Streamlit
